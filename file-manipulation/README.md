<h1>
  <span class="headline">Intro to Python for Scripting Lab</span>
  <span class="subhead">File Manipulation</span>
</h1>

**Learning objective:** By the end of this lesson, students will be able to open, read, and manipulate files with python.

Python provides powerful tools for file manipulation. In this exercise, you'll write a script to read from and write to files.

1. Create a new Python file and save it as `file_manipulation.py`.

2. Write a script that prompts the user for a filename and some text to write to the file.

3. Open the file in write mode using the `open()` function and write the user's input to the file.

4. Close the file using the `close()` method.

5. Open the same file in read mode and display its contents.

6. Run the script, provide a filename and some text, and verify that the file is created and contains the expected content.
