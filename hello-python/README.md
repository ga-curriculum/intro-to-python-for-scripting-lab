**Learning objective:** By the end of this lesson, students will be able to create a script that takes a user's input and prints a personalized message containing that input.

## Exercise 1

Let's start with an exercise to get familiar with Python scripting.

1. Ensure you are in the <code class="filepath">intro-to-python-for-scripting-lab</code> directory. If you are not, navigate to it in the terminal.

2. Create a new file named <code class="filepath">hello_python.py</code>:

   ```bash
   touch hello_python.py
   ```

3. Write a Python script that prompts the user for their name.

4. The script should also greet them with a personalized message containing their name.

5. Run the script to confirm it does what you want it to!

   > 🧠 Once you've verified you've implemented the functionality correctly, you might want to push your code so far to GitHub. Here are the commands to do that - just replace the commit message with something more informative:
   >
   > ```bash
   > git add .
   > git commit -m "commit message"
   > git push origin main
   > ```
