<h1>
  <span class="headline">Intro to Python for Scripting Lab</span>
  <span class="subhead">Exercise 1: Hello, Python!</span>
</h1>

**Learning objective:** By the end of this lesson, students will be able to create a script that takes a user input and prints the personalized message.

Let's start with an exercise to get familiar with Python scripting.

1. Open a text editor of your choice (e.g., Visual Studio Code, Sublime Text, or Notepad++).

2. Create a new file and save it with a `.py` extension (e.g., `hello.py`).

3. Write a Python script that prompts the user for their name and greets them with a personalized message.

4. Save the file and open a terminal or command prompt.

5. Run the script!
