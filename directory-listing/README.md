<h1>
  <span class="headline">Intro to Python for Scripting Lab</span>
  <span class="subhead">Directory Listing</span>
</h1>

**Learning objective:** By the end of this lesson, students will be able to us the `os` module to list files and directories.

In this exercise, you'll explore the os module in Python to work with directories and files.

1. Create a new Python file and save it as `directory_listing.py`.

2. Import the `os` module at the beginning of your script.

3. Use the `os.listdir()` function to get a list of files and directories in the current directory.

4. Iterate over the list and display the name and type (`file` or `directory`) of each item.

5. Run the script and observe the output, which should list the files and directories in the current directory.
