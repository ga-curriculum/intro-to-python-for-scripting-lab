<h1>
  <span class="headline">Intro to Python Lab</span>
  <span class="subhead">Calculator Script</span>
</h1>

**Learning objective:** By the end of this lesson, students will have created a calculator script in Python.

In this exercise, you'll create a calculator script that performs basic arithmetic operations.

1. Create a new Python file and save it as `calculator.py`.

2. Write a script that prompts the user to enter two numbers and an operator (`+`, `-`, `*`, `/`).

3. Use conditional statements (`if`, `elif`, `else`) to determine the operation based on the user's input.

4. Perform the corresponding arithmetic operation and display the result.
