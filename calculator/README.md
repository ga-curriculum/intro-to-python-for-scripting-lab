**Learning objective:** By the end of this lesson, students will be able to create a calculator that takes user input to do simple arithmetic using Python.

## Exercise 2

In this exercise, you'll create a calculator script that performs basic arithmetic operations.

1. Ensure you are in the <code class="filepath">intro-to-python-for-scripting-lab</code> directory.

2. Create a new Python file named <code class="filepath">calculator.py</code>.

3. Write a script that prompts the user to enter two numbers and an operator (`+`, `-`, `*`, `/`).

4. Use conditional statements (`if`, `elif`, `else`) to determine the operation based on the user's input.

5. Perform the corresponding arithmetic operation.

6. Display the result of the operation to the user.

7. Run the script to confirm it does what you want it to!

   > 🧠 Once you've verified you've implemented the functionality correctly, you might want to push your code so far to GitHub.
